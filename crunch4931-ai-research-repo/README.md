# Crunch4931 / Sparse Attention Diagnostics

A small reproducible research sandbox for testing **causal sparse attention**, token-salience concentration, and layer-projection drift. The reference implementation uses the Python standard library and deterministic synthetic inputs; it does not require model weights, network access, or GPUs.

## Research question

When a causal attention map is restricted to its top-*k* visible keys, how do attention entropy, mass concentration, and token-level projection statistics change? Can those effects be distinguished from changes introduced by the projection matrices themselves?

The experiment uses the following toy pipeline:

`text → hashed token features → Q/K/V projections → causal attention → top-k selection → softmax → weighted aggregation → diagnostics`

These are **small diagnostic matrices**, not weights from a trained LLM. The dataset and logs are synthetic and intended for reproducible pipeline tests.

## Quick start

Python 3.10+ is sufficient:

```bash
python -m src.pipeline --config configs/baseline.json --output results/summary.json
python -m unittest discover -s tests -v
```

The baseline run is deterministic, provided the input files and Python interpreter are unchanged. A PowerShell wrapper is also provided:

```powershell
.\scripts\run.ps1
```

| `docs/` | Mathematical specification, notes and research assumptions |

## Interpretation notes

- Higher attention entropy indicates broader key distribution; lower entropy indicates more concentrated attention.
- Top-k pruning changes the support of the softmax, so entropy must be compared under a consistent visibility window.
- Model quality, retrieval accuracy, or production anomaly-detection performance **cannot** be inferred from this toy benchmark.
- Strings such as `C4931`, `cyber&net`, and `shard_13` are ordinary labels in the synthetic data; they are not endpoints, credentials or model identifiers.

### Reproducibility

The matrices are generated from fixed seeds. To inspect the calculation, start with `src/attention.py` and `docs/attention-notes.md`. The sample file is JSON Lines so each row can be read independently.
